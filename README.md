# Bro's Tracker 💪

A gamified fitness & habit tracker built for a 3-person friend-group accountability challenge (June–December grind).

## Features

- **Points engine** across gym sessions, study time, and "good day" habits, scored in cycles with streak tracking for both gym and good-day streaks
- **Peer approval workflow** — every logged activity gets verified/voted on by the other members before it counts, so no one can just claim points
- **Live leaderboard** synced in real time across everyone's phones via Firebase Realtime Database
- **Auto-generated trash talk** based on current standings 😏
- **Installable as a PWA** — add to home screen and it runs like a native app, offline-capable via a service worker

## Stack

Vanilla JS/HTML/CSS · Firebase Realtime Database · PWA (manifest + service worker)
